a collection of Nix packages and NixOS modules for easily installing full‑featured Bitcoin nodes with an emphasis on security

Community-maintained successor to nix‑bitcoin

  • GitHub Explore the code
  • Documentation Set up your node
  • Follow on X @bitcoinix_net

Secure by default

  • Tor: with the secure-node preset, services connect out via Tor and accept inbound connections as onion services.
  • Least privilege: each service runs as its own user, confined by systemd sandboxing, network namespaces and seccomp.
  • Integrity: exactly pinned Nix dependencies, optional builds from source and signed release tags.
  • Defense in depth: an optional kernel and system hardening preset.

Services

Bitcoin Core, Core Lightning, LND, BTCPay Server, electrs, Fulcrum, mempool, Ride The Lightning and more.
