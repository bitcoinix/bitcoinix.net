# Security Policy

This repository contains the bitcoinix.net website. Security issues in
the website (for example its content, DNS or hosting setup) and in
bitcoinix itself are handled under the
[bitcoinix security policy](https://github.com/bitcoinix/bitcoinix/blob/master/SECURITY.md).

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/bitcoinix/bitcoinix/security/advisories/new).
**Do not open a public issue or pull request for a vulnerability.**
